# Master - Follower Robot Arm
The goal of this project is to construct a master and follower robot arm which is based on NULCEO-STM32F446RE.


## GOAL1
# AS5600 OLED Angle Display

 Use an STM32F446 to read the angle of a rotating magnet from an AS5600 magnetic sensor over I²C and display the angle in degrees on an OLED screen.
